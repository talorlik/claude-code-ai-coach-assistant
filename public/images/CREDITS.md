## Attribution note

Per-photographer names are not recorded here: Unsplash's photo-metadata and search
endpoints now require an authenticated API key, so the photographer for each CDN
asset could not be machine-resolved at download time without fabricating a name.
The canonical CDN source URL above uniquely identifies each photo on Unsplash; the
photographer can be looked up on the corresponding Unsplash photo page. The
Unsplash License does not require attribution, so the images are compliant as
committed. If exact credits are wanted, resolve each photo ID through the Unsplash
API and fill in the photographer column.
